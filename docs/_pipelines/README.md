# Feeds and Infrastructure

Documentation for this deployment: its feeds, environments, and infrastructure. This folder belongs to
the same owner as `_pipelines/`. Add, change, and remove documents here freely; framework updates never
change anything in this folder.

For how the framework works (configuring feeds, deploying, monitoring, troubleshooting), see the
[main README](../../README.md).

## Suggested contents

A starting point; replace this section with your own index.

- **Feeds**: what each feed exports, the source tables and indexes it uses, who owns it, and anything
  unusual about it.
- **Environments**: the workspaces and targets, and the Elasticsearch hosts each target writes to.
- **Infrastructure**: compute, networking, access, secrets (where they live, never their values).
- **Runbooks**: who to contact, and the steps your team follows for common incidents and changes.
